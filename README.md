# Projekt Chrome

Create a premium, modern portfolio website for a Polish graphic designer / visual artist / art director.

IMPORTANT: The entire website must be written in Polish.
The prompt is in English, but all visible website content, navigation, buttons, headings, labels, project descriptions, and UI text must be in Polish.

Do not use English text on the website except for brand names, project names, social media platforms, or specific design terms where appropriate.

VISUAL DIRECTION

Create a highly visual, sophisticated portfolio with a strong black + chrome identity.

Primary colors:

Deep black

Graphite

Metallic chrome

Silver

The visual style should combine:

Luxury + Futuristic + Editorial + Brutalist + High-End Graphic Design

The website should feel like the portfolio of a top-tier independent graphic designer / art director, not a generic portfolio template.

Use:

Deep black backgrounds

Metallic chrome accents

Subtle silver gradients

Realistic chrome reflections

Strong typography

Large amounts of negative space

Editorial compositions

High-quality project imagery

Avoid:

Bright colors

Purple

Blue

Neon gradients

Generic SaaS layouts

Excessive rounded cards

Corporate aesthetics

Stock-looking visuals

The overall feeling should be:

minimalist, expensive, artistic, futuristic, bold and exclusive.

TYPOGRAPHY

Use a premium modern sans-serif font such as:

Space Grotesk, Inter, Helvetica Neue, or a similar modern grotesk typeface.

Typography should be one of the main visual elements.

Use:

Very large headlines

Bold typography

Uppercase labels

Strong typographic hierarchy

Large editorial compositions

Small metadata text

Carefully controlled letter spacing

The typography should feel fashion-editorial, modern and artistic.

ANIMATIONS

Image transitions

Mouse-following elements

Smooth page transitions

Animations should feel premium and cinematic, not excessive.

Do not make the website feel like a gaming website.

All visible content on the website must be in Polish.

The only English words allowed should be proper names, brand names, social media names, or unavoidable professional terms such as Art Direction, Branding, 3D, Motion.

The final website should feel like a luxury Polish creative portfolio with an international visual standard.

The dominant visual identity must be:

BLACK + CHROME + TYPOGRAPHY + NEGATIVE SPACE + PREMIUM 3D

Make it look expensive, artistic, futuristic, minimal and memorable.
